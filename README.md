# AI 활용 게임 개발 (Unity)

## 개요
AI 활용 능력과 생산성을 높이기 위해 클리커 게임을 제작하며

기획, 리소스 제작, 프로그래밍 전 분야에 AI 활용

## 사용 기술
1. Nano Banana(이미지)
2. Grok(애니메이션)
3. ChatGPT(기획)
4. Github Copilot(프로그래밍)

## 개발 기간
2025.10 ~ 2025.11 (2개월)

## 개발 기간
프로그래머가 프레임워크와 설계, 정제에 집중하면

구현은 AI를 활용하여 생산성 극대화 가능
